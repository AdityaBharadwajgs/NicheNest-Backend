# NicheNest – Discover Handmade Treasures

## 📖 About the Project
NicheNest is a full-stack **MERN-based e-commerce platform** developed to support local artisans in showcasing and selling their handmade products online. Many talented artisans in India struggle to reach wider markets due to lack of access to big e-commerce platforms and limited technical knowledge.

This project provides a dedicated digital marketplace where artisans can connect with customers directly, grow their sales, and build a sustainable online presence. The platform is **user-friendly, responsive, and secure**, ensuring a smooth shopping experience for customers and an easy management system for artisans and administrators.

---

## ✨ Key Features

- 👤 **User Management** – Registration, login with OTP, profile management.
- 🛍️ **Product Module** – Browse, search, add to cart/wishlist, view product details.
- 📦 **Order Management** – Place orders, track order history, manage addresses.
- 🎨 **Artisan Module** – Artisans can manage their profile and upload handmade products.
- 🛠️ **Admin Dashboard** – Monitor users, products, orders, and artisans.
- 🔑 **Authentication & Security** – Role-based access, secure login/signup, password protection.
- 📜 **Wishlist & Cart** – Add/remove products easily.
- 📨 **Notifications & OTP** – Email-based OTP for account security.

---

## 🏗️ Tech Stack

- **Frontend:** React.js, Tailwind CSS, Axios
- **Backend:** Node.js, Express.js
- **Database:** MongoDB with Mongoose
- **Authentication:** JWT, Bcrypt, OTP (Nodemailer)
- **Tools:** GitHub, Postman, VS Code

## 🚀 How to Run Locally

1. Clone both repositories (Frontend & Backend).
```bash
git clone <frontend-repo-url>
git clone <backend-repo-url>
```
2. Install dependencies:
```bash
npm install
```
3. Set up **MongoDB connection** and environment variables.
4. Start backend server:
```bash
npm start
```
5. Start frontend:
```bash
npm run dev
```
6. Access the platform:
- Frontend: [http://localhost:3000](http://localhost:3000)
- Backend: [http://localhost:5000](http://localhost:5000)
